# DS Chat（安卓客户端） v1.0.2

一个轻量的安卓 AI 聊天客户端：WebView 壳 + 纯前端，用你自己的 API Key 直连
OpenAI 兼容接口，默认对接 DeepSeek（**DeepSeek-V4.1-Flash-1017**）。

> **免责声明**：本项目是个人开源项目，与 DeepSeek 官方**没有任何关联**，未经其授权或背书。
> 「DeepSeek」仅用于说明所调用的接口与模型；项目内不含其商标图形资产
> （原鲸鱼标志已移除，应用内为自绘的「DS」字母标）。界面布局参考了通用的聊天应用形态，
> 不复制官方素材。商用或发布请自行确认合规性。

> 包名 `com.dschat.app`，与官方客户端 `com.deepseek.chat` 完全独立，可与官方 App 共存安装。

- 应用名：DS Chat
- 版本：V1.0.2（versionCode 1）
- 最低系统：Android 10（API 29）
- 安装包：`build/DS-Chat.apk`（约 92 KB）

## 功能

- 流式对话（逐字显现，可在设置关闭改为一次性返回），可随时停止；思考过程可展开
- **上下文隔离**：每次请求只发送当前对话的消息，绝不携带其他对话（结构上保证）
- 按对话保存设置：每个对话单独保存模型 / 深度思考 / 联网搜索，草稿也各自保留
- 查看请求上下文：设置里可直接看到即将发出的 JSON，用来核对隔离
- 深度思考开关 + 思考强度（低/高/最高）
- 图片输入：相册选择或粘贴，最多 4 张，自动压缩到 1280px
- 联网搜索开关；参考来源折叠在「深度思考」面板里（默认收起，点开可看）
- 模型切换（V4.1 Flash / V4 Pro）
- 会话：搜索、分组、重命名、删除、编辑已发送消息、置顶、批量选择删除
- 多个对话可同时生成；按最近一次活动时间排序，谁最后完成谁在最上面（置顶区之外）
- 思考语言默认中文
- Markdown：标题、列表、表格、引用、代码块（高亮 + 复制）
- 数据：本地保存、导出 / 导入 JSON、一键清空
- 外观：跟随系统 / 浅色 / 深色

## 安装与配置

1. 安装 `DS-Chat.apk`（已复制到 `Download/DSH-Go/`）。
2. 打开：左上角「≡」→ 设置 → 填 API Key（`sk-...`，https://platform.deepseek.com 创建）。
3. 点「测试连接」，会显示账户可用模型（正常应返回 DeepSeek-V4.1-Flash）。
4. 返回对话；输入框左侧两个胶囊分别控制「深度思考」和「联网搜索」，右侧回形针发图片。

## 两个模块（顶部滑块切换）

| 模式 | 上下文 | 适合 |
| --- | --- | --- |
| **隔离对话** | 每次请求只带当前对话的消息 | 日常问答；不同项目、不同话题互不污染 |
| **共享创作** | 把所有对话按时间合并进请求（上限 40 条 / 24000 字） | 跨对话协作：设定放一个对话，正文放另一个，互相能看到 |

- 切换入口：**设置 → 工作区**（原来的顶部滑块已移入设置）。
- **两个模式的工作区互相独立**：侧边栏的对话列表各存各的（`ds.chats.isolated.v1` / `ds.chats.shared.v1`），
  切换模式就切换工作区，不会把 A 模式的对话带进 B 模式。
- 设置 → 对话 → 查看请求上下文，能看到合并后的完整 JSON（会标出来自几个对话）。
- 共享时图片只带当前对话里的，避免 base64 把请求体撑爆。

## 接入模式

设置 → 输入 API Key 上方：

| 模式 | 说明 | 默认 |
| --- | --- | --- |
| **快速模式** | 只填 DeepSeek 的 API Key；地址固定 `https://api.deepseek.com`，模型自动列出。填别家的 Key 会提示「这不是 DeepSeek 的 API Key」 | ✅ |
| **兼容模式** | 任意 OpenAI 兼容接口：自定义地址、按接口返回的模型名切换 |  |

快速模式判定：请求 DeepSeek `/models`，只接受 id 以 `deepseek` 开头的模型；
401 或返回非 DeepSeek 模型都会提示切换模式，并且不显示任何模型名。

## 第三方 / 兼容接口

- 设置里把「API 地址」改成任意 OpenAI 兼容端点（如 `https://api.openai.com/v1`），填入对应 Key 即可。
- 模型名**动态获取**：进入设置会自动拉 `GET /models`，按返回的 `id` / `name` 生成选择器；
  当前模型不在列表里时自动切到第一个（优先 `deepseek-flash`）。
- 没有 Key 或 Key 无效时不显示任何模型名（显示「请先填写 API Key」/「无法获取模型」），
  「关于」里的模型一行也显示为 `—`。
- 判断是不是 DeepSeek 端点：地址含 `deepseek` 或模型 id 以 `deepseek` 开头。
  非 DeepSeek 端点不会发送 `thinking`、`reasoning_effort`、`deepseek_web_search` 工具和
  `stream_options`，避免第三方返回 400；深度思考 / 联网搜索胶囊点击会提示不支持。

## 限额与自动压缩

设置 → 工作区：

| 项 | 隔离对话 | 共享创作 |
| --- | --- | --- |
| 单次输出上限 | 默认 256,000 tokens；有「单次输出无上限」开关 | 默认 64,000 tokens；开关按模式分别保存 |
| 对话数量 | 不限 | 上限 100 |
| 单条上下文上限 | 不限 | 等效 20M tokens（= 1M × 20 次压缩） |
| 自动压缩阈值 | 1,000,000 tokens（可改） | 1,000,000 tokens（可改） |

超过压缩阈值时，会把较早的消息交给模型压成一段中文摘要（保留事实、约定、数字、待办），
之后的请求只带「摘要 + 最近几条消息」，界面里旧消息仍然保留。

「单次输出无上限」打开后，请求不带 `max_tokens`，上面的数字变灰不可改、也不生效；
关掉后恢复使用填写的数值（原值会保留）。

共享创作里单条对话的额度按「压缩次数」计算：每满 1M tokens 自动压缩一次并计 1 次，
累计 20 次（等效 20M tokens）即到上限——此时输入框上方出现横幅提示，
该对话不再允许发送，请新开对话。生成过程中若逼近模型窗口（约 1M）会立即停止并提示。
隔离对话没有这条上限，只按阈值自动压缩。

请求前还有一道硬保护：按估算 token 数把上下文压进模型窗口（约 1M），超出会提示并省略最早的消息。

## 存储与性能

- 对话数据存 **IndexedDB**（设置里可见「存储 IndexedDB · 已用/可用」），不再受 localStorage 5MB 限制。
  浏览器/WebView 的配额大致是可用磁盘的一部分（Chrome 系列通常可取到剩余空间的相当比例，
  但不会等于手机全部容量），首次运行会调用 `navigator.storage.persist()` 申请持久化，避免被系统清理。
- 侧栏按需渲染：只渲染首屏 60 个对话，底部「显示更多」继续加载；抽屉关闭时不做渲染。
- 单个对话只渲染最近 80 条消息，顶部「加载更早」按需展开。
- 导入官方 ZIP 时分批处理（每 10 个会话让出一次主线程），避免一次性卡死。

实测 3000 个对话：启动约 0.23s，打开侧栏约 0.06s，打开对话约 0.08s（桌面 Chromium，手机略慢）。

## 版本回退与压缩

- **聊天版本**：编辑消息、重新生成之前会自动存一份快照（每个对话最多 20 份）。
  顶栏时钟图标 → 历史版本 → 恢复，即可回到修改前的内容。
- **分块压缩**：早期消息按约 12 万 tokens 一段分批摘要，滚动续写摘要，
  所以即使历史远超模型窗口（例如导入的几十万 token 对话）也能压缩成功。
- **立即压缩**：设置 → 对话 → 立即压缩当前对话；到上限时顶栏下方的横幅本身也可点击。
  手动压缩会**重置共享模式的压缩额度**并清除上限提示，压完可以直接继续聊。
- 发送前只要估算上下文接近模型窗口（约 1M），会先自动压缩，不再静默截断。
- **风格延续**：对话被压缩过后，请求里会附上最近 **5 条未压缩回复**（含当时的思考片段），
  并给出这些回复的**平均长度**，要求模型沿用相同的思考深度、结构和篇幅（不得明显过短或过长）；
  只作参考，不得逐字复述。
- **上下文上限只属于共享创作**：隔离对话不做任何上限判断，只按阈值自动压缩；
  共享创作才有累计额度、到限提示与停止生成。

## 会话排序与管理

- **置顶**：对话「⋯」菜单里置顶/取消置顶；置顶区永远在最上面。
- **排序**：置顶区内按最近活动排序；其余按 `updatedAt` 倒序分组（今天/昨天/最近 7 天/更早）。
  发送时与**生成完成时**都会刷新 `updatedAt`，所以「同一时间多个对话在生成」时，
  最后完成的那条会排到最上面（置顶之下）。
- **并发生成**：切换对话不会中断正在生成的回答，侧栏会显示一个小圆点在闪。
- **批量管理**：侧栏右上角「选择」→ 勾选 → 底部「删除」（支持全选）。
- **思考语言**：设置 → 模型 → 思考语言，默认「中文」，会在 system 消息里追加中文思考要求。

## 导入 DeepSeek 官方导出

官方导出的是 ZIP（不是 JSON），本版已支持：

```
deepseek_data-YYYYMMDD.zip
├── manifest.json              # export_format_version: 3
├── user.json
├── chat_session_index.json    # 会话摘要
└── chat_sessions/<id>.json    # 每个会话的消息树
    chat_sessions/<id>_files/  # 附件（图片会转成 data URL 一并导入）
```

- 自动识别文件头（`PK`）→ 走 ZIP 解析；否则按 JSON 处理。
- 消息树按 `parent_id` 展开为线性记录；`REQUEST` → 用户消息，`RESPONSE`/`TEMPLATE_RESPONSE` → 回答，
  `THINK` → 深度思考（含用时），`TOOL_SEARCH`/`READ_LINK`/`TOOL_OPEN` → 参考来源。
- 图片附件最多导入 12 张、单张 1.6 MB 以内，避免撑爆本地存储。
- `manifest.json` 的 `export_format_version` 大于 3 时会提示升级。

## 布局自适应

- 顶栏高度用 `clamp(50px, 7.4vh, 62px)`，矮屏自动收紧，视觉上更靠上。
- 「内容由 AI 生成，请仔细甄别」移到底栏**上方**，输入框距屏幕底部 5px。
- 窄屏（≤380px）收紧胶囊间距、隐藏语音占位；≤330px 胶囊只留图标，避免换行重叠。
- 横屏/矮屏（高度 ≤640px）自动缩小首页 Logo 与输入框最大高度。

## 流式动画

SSE 到达的是成块的 token，如果直接塞进 DOM 就会「蹦字」。这里把收到的文本先放进缓冲区，
用 `requestAnimationFrame` 按帧均匀释放（约 60–120 字/秒，积压多时自动加速），
文字像水一样淌出来；请求结束时会把缓冲一次性排空再落库，不会丢字。

## 上下文隔离与流式开关

**上下文隔离是结构性的**：`buildContext(chat)` 只遍历当前对话的 `messages`，
请求体里不可能出现其他对话的内容。设置页「对话 → 查看请求上下文」会把即将发送的
JSON 原样列出来（可复制），可以自己核对。

设置页「对话」分组：

- **流式输出**：开（默认）时边生成边显示；关闭后请求 `stream:false`，一次性返回完整回复。
- **按对话保存设置**：开（默认）时每个对话各自保存 `model / thinking / webSearch` 与输入草稿；
  关闭后所有对话共用一套全局设置。这只影响设置，不影响上下文。
  开启时「默认模型 / 思考强度」只对新建对话生效，可用「应用到当前对话」同步。

唯一会被所有对话共享的文字是设置里的**系统提示词**——它本来就会作为
`system` 消息发给每次请求，注意不要往里写只属于某个对话的内容。

## 实现说明

- 页面运行在 `https://app.local`（`shouldInterceptRequest` 从 assets 返回），属安全上下文；
  官方接口会回显 `Access-Control-Allow-Origin`，因此 WebView 内 `fetch` 可直接读 SSE。
- 所有模型输出先 HTML 转义再渲染 Markdown；链接只允许 `http(s)`。
- 带 `tools` 时按官方要求回传历史 `reasoning_content`。
- 导出写入 `Download/DeepSeek/`（MediaStore，无需存储权限）。
